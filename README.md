# CS2 SKINS

Бесплатная браузерная игра-симулятор коллекционирования виртуальных скинов.

## Возможности
- Открытие кейсов с разной стоимостью
- Апгрейд предметов с расчётом шанса
- Инвентарь, фильтры, сортировка и продажа предметов
- Ежедневный бонус и задания
- Достижения, уровни и опыт
- Локальное сохранение прогресса
- Экспорт и импорт сохранения

## Запуск
Открой `index.html` в современном браузере.

## Публикация
Можно бесплатно опубликовать проект через GitHub Pages.

## Важно
Это фанатская игра. Предметы, цены и монеты виртуальные.
Нет настоящих скинов, денежных платежей или вывода средств.
Проект не связан с Valve.
